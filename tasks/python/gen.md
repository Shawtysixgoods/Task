## Практическое задание: Анализатор логов интернет-магазина
Контекст: Вы получили выгрузку сырых данных о покупках за день. Каждый лог — это строка формата данные_пользователя:ID_товара:сумма_покупки.
Вам нужно очистить эти данные, отфильтровать их и составить аналитические отчеты с помощью генераторов коллекций и срезов.
## Исходные данные
Скопируйте этот список в свой код:
```
raw_logs = [
    "user12_id8492:prod_442:2500",
    "admin_id0000:prod_000:0",
    "guest_id1111:prod_111:150",
    "user05_id3341:prod_885:12000",
    "user12_id8492:prod_442:2500",  # Повторяющаяся покупка
    "user22_id9102:prod_112:550",
    "user05_id3341:prod_990:4300",
    "admin_id9999:prod_001:10",
    "user12_id8492:prod_771:800",
    "guest_id2222:prod_111:150"
]
```
------------------------------
## ТЕХНИЧЕСКОЕ ЗАДАНИЕ## Шаг 1: Фильтрация и очистка (Срезы и Генератор списков)
Используя генератор списков и срезы, создайте новый список clean_logs.

* Отфильтруйте логи: исключите всех пользователей, чей логин начинается на "admin" или "guest" (используйте срезы для проверки первых 5 или 4 символов).
* Результатом генератора должен быть список кортежей вида: (ID_пользователя, ID_товара, сумма_int).
* Подсказка: Чтобы достать ID пользователя (например, 8492 из user12_id8492), найдите индекс символа _ или используйте фиксированный срез, если это возможно, а сумму приведите к типу int.

## Шаг 2: Уникальные товары (Генератор множеств)
Используя генератор множеств, соберите из списка clean_logs все уникальные ID товаров.

* Назовите переменную unique_products.
* В множество должны попасть только те товары, стоимость которых строго больше 600.

## Шаг 3: Программа лояльности (Генератор словарей)
Маркетологи хотят посчитать, сколько всего денег потратил каждый реальный клиент (сумма покупок по каждому ID пользователя).

* Используя генератор словарей, создайте словарь user_spending, где:
* Ключ — ID пользователя (строка).
   * Значение — общая сумма его покупок (число).
* Подсказка: Так как у одного пользователя может быть несколько покупок, встроенный генератор словарей перезапишет значение последней покупкой. Чтобы этого избежать, для подсчета суммы внутри генератора можно использовать встроенную функцию sum() со вложенным генератором, который фильтрует clean_logs по конкретному пользователю.

## Шаг 4: Работа со срезами результатов
Выведите на экран:

   1. Топ-2 самых дорогих лога из списка clean_logs (предварительно отсортировав его по сумме в обратном порядке), используя срезы.
   2. ID пользователей из словаря user_spending в развернутом (обратном) порядке, используя срез [::-1].

## Подсказка по синтаксису для самопроверки:

* Генератор списка: [x for x in ... if ...]
* Генератор множества: {x for x in ... if ...}
* Генератор словаря: {k: v for k, v in ...}
* Шаблон среза: sequence[start:stop:step]
